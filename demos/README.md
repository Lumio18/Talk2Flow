# Demos

End-to-end Talk2Flow scenarios with all artifacts visible. Each demo runs the complete pipeline (or its current state) on a real-world scenario and exposes every intermediate output.

Demos serve two audiences:

- **Prospective users** — to decide whether Talk2Flow fits their use case
- **Contributors** — to see how a complete pipeline run looks and validate new skills against expected behavior

## Available demos

| Demo | Status | Scenario |
|---|---|---|
| `pme-order-management/` | ✅ Reference quality — V1 flagship | Small artisanal e-commerce founder automating email order processing |

## Adding a demo

Open a discussion before proposing a new demo. Reference-quality demos are a bigger commitment than skill contributions — they're the public face of Talk2Flow.

A good demo must:
- Have a clear, universally understandable scenario
- Run the complete pipeline (no shortcuts)
- Include every intermediate artifact, anonymized
- Be reviewable by someone outside the original team
